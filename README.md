# alhuissi.com

Personal site for Alfredo L’huissier. Source for the GitHub Pages-hosted portfolio.

The complete site is in `site/` and deployed by `.github/workflows/deploy.yml`.

No framework or runtime dependencies are required: HTML, CSS, a little JavaScript, and real project media. Edit the files, commit to `main`, and GitHub Actions publishes the changes once Pages is configured to use GitHub Actions.

Do not add the `CNAME` file or change DNS until the custom-domain cutover is planned.
